# Sopinha de Letrinhas

Aplicacao web feita com React, Vite e Tailwind CSS.

## Abrir o site manualmente

1. Instale o [Node.js](https://nodejs.org/) (inclui o npm).
2. Abra o PowerShell e entre na pasta do projeto:

   ```powershell
   cd C:\Users\Usuario\sopinha_de_letrinhas
   ```

3. Instale as dependencias (necessario na primeira vez):

   ```powershell
   npm install
   ```

4. Inicie o servidor local:

   ```powershell
   npm run dev
   ```

5. Abra no navegador o endereco exibido pelo Vite. Neste projeto, o endereco padrao e `http://localhost:8443`.
6. Para encerrar o servidor, volte ao PowerShell e pressione `Ctrl+C`.
